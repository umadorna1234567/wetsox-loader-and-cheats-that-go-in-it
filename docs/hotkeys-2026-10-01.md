# Dedicated hotkeys

Implemented a separate per-game Hotkeys page with offscreen reveal/highlight and
per-toggle Key links. All gameplay keybind rows are filtered out of Home and
section cards. Old aim/teleport configs retain their bindings. Rules live inside
the existing config values under `_hotkeys`; default aim retains Hold/RMB.

The feature switch is the master enable. A disabled hotkey uses its normal state;
Hold requires key down; Toggle starts off and flips once per fresh press. Disabled
master switches, changed bindings/modes, recording and foreground changes reset
or suppress input as appropriate. One-shot JC4 teleport bindings retain their
press action and have a dedicated enable switch. Menu shortcut stays keyboard-only.

Shared loader polling evaluates all 27 distinct toggle keys across FC4/FC5/JC4,
including filters, prediction toggles, ESP styles, ammo, FOV, boost and grapple.
Controllers are sampled once per poll, only when configured and game-focused.
IPC v6 prevents old DLLs silently applying new activation semantics. Game backends
retain foreground/menu checks for aiming. Updated source, deployment and archives
must be kept together. No physical-controller gameplay test was performed in this
change; state-machine, controller mapping, IPC and Qt interaction tests cover the
implemented behavior.
