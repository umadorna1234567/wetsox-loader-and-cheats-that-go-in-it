# Fix-first changes, 2026-09-30

- Installed-pack readiness replaces the Far Cry 5-only READY badge.
- Breadth-first package discovery handles extraction wrappers (up to eight nested
  levels / 4096 directories), rejects escaping module paths, and prefers direct
  installs for duplicate IDs. Missing artwork no longer hides a valid module.
- Main layout: Wetsox.exe, backend, cheats, configs. Native launcher forwards CLI
  arguments; application/helper/config resolution no longer depends on cwd.
  Existing root settings migrate into configs/settings.json.
- Far Cry 4 aim alignment uses an eight-degree world-space angle bound instead of
  projection error. Camera validity/position, collision, lifetime and bounded
  write guards remain. Tests cover multiple aspect ratios and scope zoom factors.
  We have not confirmed the fix on the users reporting 1440p failures.
- Shared XInput capture/holding supports four controller slots, face/shoulder/menu
  buttons, D-pad, stick clicks/directions and analog triggers. Already-held inputs
  are ignored when starting capture. Keyboard and mouse bindings remain supported.
  Hardware controller confirmation is pending; protocol and decoding tests passed.
- Just Cause 4 gameplay code was imported from the supplied Solis source. Its
  proxy entry point and menu are excluded. Wetsox uses its own session bridge,
  MinHook installation, Qt controls, configs and keybind capture. All original
  feature settings and waypoint/objective actions are exposed. The generic
  Configs reset serves the old menu's reset function.
- JC4 retains Steam build 4110618 checks and original torso-estimate/no-wall-check
  aim behavior. Corresponding DLC/unlocks are needed for special movement options.
  Artwork is an original vector placeholder; it can be replaced through the editor.
- Local Solis xinput9_1_0.dll was hash-verified against the supplied build and
  renamed to xinput9_1_0.dll.solis-backup while the game was closed. No original
  game file was replaced. Restore that filename only after removing/disabling the
  Wetsox JC4 session and restarting the game.
- Shared session protocol is v5: update loader and packs together, restart games.

settings/controller binding transfer, controller thresholds/mappings, nested
package discovery, camera math, JC4 tuning math, and the real JC4 Qt menu smoke

initial verification. Feature-by-feature gameplay confirmation remains pending.
