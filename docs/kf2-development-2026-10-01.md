### Zed-only outline occlusion and FPS correction
User requested automatic Zed-vs-Zed occlusion (only exposed parts of a rear Zed outline), while retaining through-wall outlines and adding no toggle. Also reported significant silhouette FPS loss.

Replaced independent per-character masks with a shared perspective-correct depth mask per character category. Only character triangles enter these masks; map/wall depth never enters, so through-wall visibility remains. Closest Zed owns each pixel; boundaries between overlapping Zeds belong to the closer one. Players use a separate layer. Raster resolution bounded to 960x540, reused each frame. Joined boundary segments into paths and simplified them within 0.8 raster pixels to reduce native Canvas calls. Bone inverse/pose/world transforms composed once per bone per frame instead of repeated quaternion transforms per vertex influence. Draw2DLine now caches reflected function/parameter offsets and reuses its parameter buffer, avoiding allocations/reflection lookups on every edge. Basic offscreen culling precedes mesh skinning.
