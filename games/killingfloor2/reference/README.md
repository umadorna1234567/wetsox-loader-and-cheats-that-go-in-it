# KF2 reference provenance

The SDK headers, Main.cpp, Signatures.cpp, and UE.h in this directory are research references from https://github.com/Jurugi/KF2-UE3-Hook (master, retrieved 2026-10-01). Its MIT license is retained in LICENSE. They are not compiled into this pack as a complete SDK. The global-array and event signatures informed reflection.hpp; live property/function layouts were independently checked against the installed Steam build.

Additional weapon behavior reference: https://github.com/GenZmeY/KF2-Game-Scripts/blob/master/KFGame/Classes/KFWeapon.uc. The downloaded research copy is under build-Release/kf2-research and is not packaged.
